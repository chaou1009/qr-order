扫码点单 · 收银电脑安装说明（Windows 10 / 11）
==============================================

这套程序装在收银电脑上。电脑开机后它会自己在后台运行，不会出现黑色窗口。
平板和手机只需要用浏览器打开网址，不用装任何 App。


一、准备（只做一次）
----------------------
1. 在 Cloudflare 买好网址（例如 ordertastychickenrice.com）。
2. 收银电脑要能上网，并且一直插着电。


二、在 Cloudflare 网站拿“隧道 Token”（约 5 分钟）
----------------------------------------------
隧道 = 让客人从外面用网址连到你店里这台电脑，不用去改路由器。

1. 登录 dash.cloudflare.com，左边选 “Zero Trust”。
   （第一次进去会叫你取一个团队名字，并选 Free 免费方案，照着点就可以。）
2. 左边选 Networks（网络）→ Tunnels（隧道）→ “Create a tunnel / 创建隧道”。
3. 类型选 “Cloudflared”，名字随便填，例如 shop-pc，然后保存。
4. 下一页选 Windows，会看到一行很长的指令，里面有一段以 eyJ 开头的文字。
   点旁边的复制按钮，把整行复制起来（先贴到记事本也可以）。
   ★ 这一行不用自己去运行，等一下安装程序会叫你贴进去。
5. 按 Next，到 “Public hostname / 公共主机名” 这一页：
     Subdomain（子域名）：留空
     Domain（域名）：选 ordertastychickenrice.com
     Type（类型）：HTTP
     URL：localhost:3000
   然后保存。


三、安装（约 5 分钟）
----------------------
1. 先关掉 Demo 的黑色窗口（如果还开着）。
2. 把收到的 zip 解压（右键 → 全部解压缩），打开解压出来的文件夹。
3. 双击 “1-安装.bat”。Windows 问“是否允许更改”时，点“是”。
4. 跟着窗口的英文提示做，一共 7 步：
   第 3 步 菜单：程序会自己找到你在 Demo 里设好的菜单和照片，直接按 Enter 就用最新那份。
           如果 Demo 在另一台电脑：先在 Demo 后台 → 店铺资料 → 下载备份，把 zip 拷过来，
           这一步输入 Z，再选那个 zip。
   第 4 步 网址：输入 ordertastychickenrice.com，按 Enter。
           员工密码：自己定 4 到 8 位数字（不能用 1234、8888、0000），平板登录时要用。
   第 7 步 隧道：在窗口里点右键，就会贴上刚才复制的那行，按 Enter。
5. 看到绿色的 “All done!” 就完成了。桌面会多两个图标：
   QR Order - Staff（员工接单）、QR Order - Back office（后台）。
6. 程序已经搬到 C:\QROrder，下载的 zip 和解压出来的文件夹可以删掉。

安装做了这些事：
- 程序放在 C:\QROrder，菜单、订单、照片都在 C:\QROrder\data
- 电脑开机就自动启动（不用登录 Windows 也会启动）
- 如果程序意外停了，5 秒后会自己重新启动
- 插电时电脑不会睡眠（屏幕自己关掉没关系）
- Cloudflare 隧道也会跟着电脑开机自动连线


四、装好后
----------
1. 平板用 Chrome 打开 https://ordertastychickenrice.com/staff ，输入员工密码。
   后台是 https://ordertastychickenrice.com/admin
   建议在 Chrome 右上角选 “添加到主屏幕”，以后一点就开。
2. 在后台 → 桌台，重新打印桌上的二维码。
   ★ 一定要在填好网址之后才打印，旧的 Demo 二维码不能用。
3. 用自己的手机（关掉 Wi-Fi、用流量）扫一张桌码，下一张测试单，看平板有没有响。


五、日常
--------
- 每天照常开关电脑就可以，什么都不用点。
- 有新版本时：双击 C:\QROrder 里的 “更新.bat”。
  它会先备份，再下载新版本；新版本开不起来会自动退回旧版本，菜单和订单都不会丢。
- 好像卡住、平板连不上：双击 C:\QROrder 里的 “重启.bat”。
- 备份：在后台 → 店铺资料 → 下载备份，存到你的云端（Google Drive 等）。
  建议每星期一次，或改了很多菜单之后。


六、要注意
----------
- 不要在营业时间重启电脑或让 Windows 更新重启。
  可以到 设置 → 更新和安全 → Windows 更新 → 更改使用时段，把营业时间填进去。
- 收银电脑关机时，客人就不能扫码点单（会显示打不开）。
- 想改员工密码：再双击一次 “1-安装.bat”，第 4 步输入新密码，其它步骤按 Enter 跳过。
- 有问题时，把窗口拍照发过来；运行记录在 C:\QROrder\data\logs。
