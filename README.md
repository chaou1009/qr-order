# 餐厅扫码点单系统（第一阶段）

单个餐厅使用的扫码点单。一个 Node.js 程序 + 一个 SQLite 数据库文件，**没有任何第三方依赖**，一台最便宜的云服务器就能跑。

## 已完成（第一阶段）

| 部分 | 网址 | 功能 |
|---|---|---|
| 顾客点单 | `/t/<桌台码>`（扫桌上的二维码打开） | 分类菜单（图片、价格、售罄）、规格/加料/备注、购物车、下单、"我的订单"（只显示这台手机的订单）、英文/马来文/中文切换，下单后提示"用餐愉快，请到柜台付款" |
| 接单平板 | `/staff` | 员工密码登录、按桌号显示待输入订单、新订单响铃 + 横幅提示、"已输入收银机"按钮（可撤回）、作废订单、"桌台"页查看每桌用餐状态并清台、历史订单、屏幕常亮、每 4 秒自动刷新 |
| 桌台二维码 | `/staff/qr` | 生成每张桌子的固定二维码，直接打印贴在桌上 |

**开台 / 清台 / 扫码激活：** 客人扫桌上二维码时自动开台，同桌的其他手机扫码会加入同一场。扫码后网址里的桌台码会从浏览器记录中去掉。员工在平板"桌台"页点"清台"后，这一场所有手机的点单页都会失效，必须重新扫桌上的二维码才能再点，所以已经离开的客人无法从浏览器记录里继续下单。超过 1 小时没有新订单的桌子会自动清台。顾客可以查看"我的订单"（含是否已确认）和"本桌订单"（这一场的合并清单和合计）。

**呼叫服务员与催菜：** 顾客可点铃铛呼叫服务员（加水、餐具纸巾、酱料辣椒、请过来），也可以在订单页勾选还没上的菜提醒厨房；每道菜的一般烹制时间（`seed.json` 里的 `cook_minutes`，第二阶段可在后台设置）加上忙碌时的额外时间到了之后才能勾选。平板会以不同铃声和蓝色/橙色卡片提醒，员工点"已处理"即可。

**出餐忙碌状态：** 平板顶部"出餐：正常 / 忙碌 / 非常忙碌"，忙碌时顾客点单页显示礼貌的等待提示（约多等 10 / 20 分钟）。

**二维码防改桌号：** 每张桌子的二维码里是一串随机码（例如 `/t/jMifrlVh1mii`），不是桌号本身。客人改网址也猜不到别的桌的码，所以二维码可以一直固定使用。

## Windows 一键试用

双击 `start-demo.bat`。需要 `runtime\node.exe`：打包好的 Demo 压缩包里已自带；从 GitHub 下载代码的话，请把 [Node.js 22 Windows 版](https://nodejs.org/dist/latest-v22.x/) 压缩包里的 `node.exe` 放进 `runtime` 文件夹。浏览器会自动打开试用说明页，员工密码 8888。
第一次运行时 Windows 防火墙可能弹窗，请点"允许"，这样同一 WiFi 下的手机才能连进来。

## 本地试用（命令行）

需要 Node.js 22.13 或以上。

```bash
RESTAURANT_NAME="店名" STAFF_PIN=8888 node server.js
```

打开 http://localhost:3000/staff 登录 → 再打开 http://localhost:3000/staff/qr 看到每张桌子的二维码和网址，点任一网址即进入顾客点单页。

## 省钱上线：店里的电脑当服务器（推荐）

不用租云服务器，每月只花电费。一年只需一个域名的费用（约 RM 40–60）。

1. 准备一台营业时间一直开着的电脑：旧笔记本、迷你主机都可以。最好不要用收银机本身，以免互相影响。
2. 在这台电脑上运行本系统（和 Demo 一样，双击启动；正式使用时我可以帮您设成开机自动运行）。
3. 用 **Cloudflare Tunnel**（免费）把它连到您的域名，例如 `https://order.您的店名.com`：
   - 不需要固定 IP，也不需要在路由器上开端口
   - 自动 HTTPS
   - 客人用手机流量也能点单，不必连店里 WiFi
4. 启动时设 `PUBLIC_URL=https://order.您的店名.com`，再打开 `/staff/qr` 打印二维码。

**更省（零费用）的做法：只用店内 WiFi。** 不买域名，二维码直接指向这台电脑的局域网地址。缺点是客人必须先连上店里 WiFi 才能点单，而且要在路由器里给这台电脑固定 IP，否则地址变了二维码就失效。

注意：店里断电、断网或电脑关机时无法点单。数据在这台电脑的 `data` 文件夹，请定期备份。

## 云服务器部署（备选）

推荐一台新加坡机房的小型云服务器（1 核 1GB 足够，约 US$4–6/月，例如 DigitalOcean、Vultr、Lightsail），加一个域名。马来西亚无需 ICP 备案。

1. 服务器上安装 Docker。
2. 把本文件夹上传到服务器。
3. 修改 `docker-compose.yml` 里标了 `CHANGE` 的三处：店名、员工密码、域名。
4. 域名的 A 记录指向服务器 IP。
5. 运行 `docker compose up -d`。HTTPS 证书会自动申请。
6. 平板打开 `https://你的域名/staff`，登录后点"开始接单"（需要点一下才能响铃）。
7. 打开 `https://你的域名/staff/qr` 打印二维码。

**数据备份：** 所有数据都在 `data/` 文件夹（`restaurant.db`），定期复制这个文件夹即可。

## 设置项（环境变量）

| 变量 | 说明 | 默认 |
|---|---|---|
| `RESTAURANT_NAME` | 店名（顾客页、二维码上显示） | `My Restaurant` |
| `STAFF_PIN` | 平板登录密码 | `1234`（上线前必须改） |
| `PORT` | 端口 | `3000` |
| `DATA_DIR` | 数据库位置 | `./data` |
| `AUTO_CLOSE_HOURS` | 多少小时没有新订单自动清台 | `1` |
| `PUBLIC_URL` | 正式网址，二维码会用它 | 空（自动用当前网址） |

品牌主色可在 `public/app.css` 顶部的 `--accent` 修改。
